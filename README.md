# 海洋科學調查筆記本

依國家海洋研究院《海洋科學序列教材（OSS）G3–G5 初階海洋素養》設計的線上互動遊戲。學生跟著遊戲角色「海博士」，像海洋科學家一樣觀察、收集證據、用證據解釋海洋。每一節都對照教師手冊的教學流程，學生可以自己一站一站完成。

- **線上網址：<https://ocean-notebook-tw.github.io/>**
- 適用對象：國小三到五年級
- 使用裝置：電腦、平板、手機的瀏覽器都可以，不需要安裝或登入

## 目前完成的單元

| 節次 | 名稱 | 遊戲內容 | 直接開啟 |
|---|---|---|---|
| 1.1 | 海洋星球 | 第一個想法、證據與感覺分類、3D 地球儀探索（找海洋、描最長路線、看見大部分是水）、討論模型、拋接地球儀（正字記錄與 71% 比例圖）、海洋星球回顧 | [開啟 1.1](https://ocean-notebook-tw.github.io/#u11) |
| 2.1 | 介紹海洋生物 | 第一個想法、16 張生物適應圖卡的生物之旅、分享與聆聽、逐步完成《生物需求》圖表（動物的食物、呼吸與魚鰓、類植物生物）、回顧 | [開啟 2.1](https://ocean-notebook-tw.github.io/#u21) |

其他節次在首頁標示「製作中」。

## 功能

- **海博士 AI**：開放式題目旁有「海博士的回饋」，依教師手冊引導學生補充想法與證據，不打分數；每個單元右下角可以「問海博士」。尚未連接 AI 或連線失敗時，自動改用教師手冊整理的提示。串接方式見 [docs/AI-API.md](docs/AI-API.md)。
- **單元選單**：首頁依教材的三個單元排列，顯示每一節的進度。
- **調查筆記本**：學生的想法、選擇和發現自動記錄，可隨時打開；完成後可一鍵複製筆記本內容交給老師。
- **概念牆、科學詞彙、徽章**：隨著進度解鎖教材中的關鍵概念。
- **教師手冊對照**：每一站標出對應的手冊頁碼與步驟。
- **進度保存**：學生的名字和每個單元的進度存在該台裝置的瀏覽器裡，關掉再開也會保留；按「重新開始」可以清除。

## 網站發布方式

網站使用 GitHub Pages 發布：repo 為 Public，Settings →「Pages」設定為 Deploy from a branch、`main` 分支、`/ (root)` 資料夾。

**更新網站**：在 repo 首頁點「Add file」→「Upload files」，把新的 `index.html`（或修改過的檔案）拖進去，按「Commit changes」。1–2 分鐘後網站自動更新，網址不變。

**自行架設一份**：Fork 這個 repo，或把所有檔案上傳到你自己的 Public repo，再依上面的方式啟用 Pages，網址會是 `https://<帳號或組織>.github.io/<repo 名稱>/`。

## 在自己電腦上打開

直接用瀏覽器開啟 `index.html` 就能使用，不需要網路（字型會改用電腦內建字型）。

## 修改與新增單元

網站由 `src/` 裡的檔案組合而成，修改後執行：

```bash
python3 build.py
```

就會重新產生 `index.html`。

| 檔案 | 內容 |
|---|---|
| `src/head.html` | 頁面標題與所有樣式（顏色、字型、版面） |
| `src/body.html` | 網站外框（頂部列、路線、概念牆側欄） |
| `ai-config.js` | 海博士 AI 的 API 網址設定（改這個檔案不用重新建置） |
| `src/common.js` | 共用工具與學生姓名 |
| `src/ai.js` | 海博士 AI 回饋區塊與「問海博士」對話框 |
| `src/content/qa-1-1.json` | 1.1 各題的教材依據（預期想法、關鍵概念、提示），給 AI 與提示模式使用 |
| `src/art.js` | 生物插圖 |
| `src/unit-1-1.js` | 1.1 海洋星球 |
| `src/unit-2-1.js` | 2.1 介紹海洋生物 |
| `src/site.js` | 首頁單元選單與網址導覽 |
| `src/land-110m.geojson` | 地球儀的陸地資料 |

新增單元：仿照 `unit-2-1.js` 建立新檔（例如 `unit-2-2.js`，模組名稱 `UNIT22`），把檔名加入 `build.py` 的 `UNIT_FILES`，並在 `src/site.js` 的 `UNITS` 加上 `u22: UNIT22`、在 `CATALOG` 對應節次加上 `'u22'`。
